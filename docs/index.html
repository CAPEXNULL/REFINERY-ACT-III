Reproduce the CPU application

Clone the public repository, install requirements.txt in a Python 3.13 virtual environment, then run python -m amd.server. Open http://127.0.0.1:8765/industry. No API key is required.

The engineering prototype uses a synthetic three-component unit model. It issues no equipment commands and has not been qualified against a real plant. Similarity scores are not calibrated probabilities. Forecasts depend on stated assumptions.
